## 2026-04-03 - Accessible and Interactive Contact Section
**Learning:** Replacing raw HTML inputs with Shadcn components (`Input`, `Textarea`, `Label`) and correctly associating them with `id`/`htmlFor` significantly improves screen reader accessibility. Additionally, converting static contact text (email, WhatsApp) into interactive links (`mailto:`, `wa.me/`) with clear focus states enhances user delight and convenience.
**Action:** Always prioritize Shadcn UI components for forms and ensure all contact information is actionable through standard URI schemes.
