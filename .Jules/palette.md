## 2025-01-24 - [Accessible Form Validation with Shadcn]
**Learning:** When using Formspree's `ValidationError` with Shadcn components, wrapping the error in a `div` with `role="alert"` and a unique `id` ensures that `aria-describedby` correctly links the input to the error message, and screen readers announce the error immediately when it appears. Additionally, when migrating from raw HTML inputs with custom vertical padding (e.g., `py-3`) to Shadcn UI components, adding the `h-auto` class prevents height conflicts or layout shifts while maintaining the desired touch target size.
**Action:** Always wrap `ValidationError` in a `role="alert"` container and use `h-auto` for Shadcn inputs when custom vertical padding is required to preserve the design system's aesthetic without compromising component integrity.
