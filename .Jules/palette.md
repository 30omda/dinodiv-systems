## 2026-03-24 - [Enhance Contact Section Accessibility and Interactivity]
**Learning:** Contact forms using only placeholders lack accessibility for screen readers. Static contact information (email, phone) in a contact section should always be interactive to improve UX and reduce friction.
**Action:** Always add `<Label>` components (with `sr-only` if placeholders are preferred visually) and convert static contact text into actionable links (e.g., `mailto:`, `wa.me/`).
