## 2024-05-24 - Interactive Contact Accessibility
**Learning:** Converting static contact strings (Email, WhatsApp) into semantic interactive links (`mailto:`, `wa.me/`) with `focus-visible:ring` states provides a critical bridge for keyboard users and mobile accessibility, transforming passive information into an actionable UI.
**Action:** Always scan for contact-related text in footers or sections and wrap them in semantic anchor tags with consistent hover/focus styling.
