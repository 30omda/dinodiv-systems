## 2025-05-15 - [Interactive Contact Links]
**Learning:** Converting static contact information (email, phone) into interactive links (`mailto:`, `wa.me:`) significantly improves mobile usability and user engagement. Using `-mx-1 px-1` on inline links expands the clickable area without affecting text alignment, which is crucial for accessibility on touch devices.
**Action:** Always wrap contact details in semantic `<a>` tags with consistent focus-visible and hover states (`hover:underline`, `focus-visible:ring-1`).
